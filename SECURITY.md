# Security

Please use GitHub's private vulnerability reporting for security-sensitive
reports about an ICQ² release or this download mirror. Do not place exploits,
credentials, personal data, signing material, or unredacted logs in a public
issue.

If a release looks suspicious, stop using that file and include its exact file
name, release URL, SHA-256, Windows signature status, and observed publisher in
the private report. Never upload credentials or signing keys.
