# ICQ² Downloads

This is the official binary release mirror for **ICQ²**, published by
**I Seek You Too LLC · Oklahoma · United States**.

- Main site: <https://icq2.net/>
- Releases: <https://github.com/ISeekYouTooLLC/icq2-downloads/releases>
- Windows publisher: `I Seek You Too LLC`

This repository contains release-facing metadata and prebuilt release files.
It does not publish the private ICQ² source repository.

## Verify a Windows download

1. Open the file's **Properties → Digital Signatures** page.
2. Require a valid signature from `I Seek You Too LLC`.
3. Compare the file's SHA-256 with `SHA256SUMS.txt` from the same release.
4. Do not disable SmartScreen, antivirus, or organization security policy.

A checksum detects accidental corruption and lets mirrors be compared. It does
not replace the Windows digital signature.
